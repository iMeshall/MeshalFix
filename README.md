# 🛠️ Meshal Fix Toolkit

A practical Windows 10/11 repair toolkit designed to help diagnose and fix common Windows and PC issues through simple, menu-driven tools.

Built to make Windows troubleshooting and repair easier for everyone.

## ✨ Features

### 🧹 Cleaning

* Clean temporary files and common Windows caches
* Clean NVIDIA DirectX Shader Cache
* Remove unnecessary temporary data

### 🔧 Windows Repair

* DISM health checks and repairs
* SFC system file verification and repair
* CHKDSK disk checks
* Windows component repair

### 🌐 Network Fixes

* Reset Winsock
* Reset TCP/IP
* Flush DNS
* Renew IP configuration
* Repair common network-related issues

### 🎮 Gaming Fixes

* Game-related troubleshooting
* Shader cache cleanup
* Launcher and gaming component fixes
* Xbox / Microsoft Store gaming components
* DirectX and Visual C++ related checks
* DDU / NVIDIA driver tools
* Game Doctor diagnostics

### 🪟 Windows Update

* Troubleshoot Windows Update
* Reset Windows Update components
* Repair common update-related issues

### 🛡️ System Tools

* System information
* Hardware and Windows diagnostics
* System reports
* Restore Point creation
* Useful Windows repair utilities

### 🔄 Restore Defaults

Tools for restoring selected Windows settings to their default configuration.

## 🎯 Purpose

Meshal Fix Toolkit brings common Windows repair and troubleshooting procedures together in one easy-to-use interface.

The goal is simple:

> **Diagnose the problem → Apply the appropriate fix → Get Windows working normally again.**

The toolkit focuses on **repair and troubleshooting**, rather than unnecessary Windows tweaks or performance modifications.

## 💻 Requirements

* Windows 10
* Windows 11
* Administrator privileges

## 🚀 Usage

1. Download the toolkit.
2. Run the `.bat` file as Administrator.
3. Select the required category from the menu.
4. Follow the instructions shown on screen.
5. Restart Windows when required.

## ⚠️ Important

Some repair operations may modify Windows system components, network configuration, services, or other system settings.

Review the description of each operation before running it.

When applicable, the toolkit asks for confirmation before applying changes.

## 📋 Logs & Reports

Repair logs and generated reports are stored in:

```text
Desktop\MeshalFix_Logs
```

These logs can help with troubleshooting and reviewing operations performed by the toolkit.
